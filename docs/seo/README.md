# SEO Mixt

Source de vérité pour rédiger les pages et articles qui doivent ranker.

- `synthese-seo.md` : conclusions, plan d'action, détail par grappe (mots-clés cibles, volumes, questions, SERP, garde-fous). **À lire avant d'écrire une page.**
- `data-ahrefs.md` : données brutes Ahrefs (4 lots de mots-clés, 7 SERP, bilan mixt.care, Feeli).
- `data-google-keyword-planner.md` : volumes Google Ads (fourchettes, acné masquée).
- `liens-cibles.md` : sites à contacter pour obtenir des liens.

## Pour rédiger une page
1. Ouvrir la grappe concernée dans `synthese-seo.md` : title et H1 = requête principale (nom nu du problème).
2. Chaque sous-thème et chaque question listés = un H2 ou une entrée de FAQ.
3. Vérifier les garde-fous (généralistes, médicaments, grossesse), puis passer la copy dans `.claude/skills/copy-conforme` et `anti-ia-copy`.

Données de novembre 2026. À rafraîchir tous les 6 mois.
